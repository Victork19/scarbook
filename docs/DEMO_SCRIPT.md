**0:00–0:10** — “Scarbook makes contradictory evidence change what an autonomous agent is allowed to do.” Show `LIVE RYO` and `SOL`.

**0:10–0:25** — Start session. Show T0 verdict bullish, low risk, RSI14, timestamp, and hash. Show the agent proposal `LONG 1.0`. Click **Commit decision**.

**0:25–0:40** — Click **Second live read**. Show the two distinct receipts and the verdict transition bullish → bearish. Point to the generated `SC-001 LONG BLOCKED` citation.

**0:40–1:00** — Start a fresh session. Explain that the conversation did not carry over; only current evidence and active constraints did. Show the fresh proposal rejected by the action gate, then the final replanned decision `NO NEW POSITION`.

**1:00–1:15** — Click **Wipe active**. Show `SC-001 INACTIVE`, while the historical ledger remains.

**1:15–1:30** — Close with: “Memory tells an agent what happened. Scarbook changes what it can do next.”
