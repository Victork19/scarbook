# Related work and differentiation

**Persistent memory** answers: “What happened before?”

**Runtime guardrails** answer: “Is this action currently permitted?”

**Scarbook** composes live evidence, an explicit commitment, a fresh cross-read, deterministic contradiction detection, provenance-bound constraint compilation, fresh-session gating, and replanning.

Scarbook does not claim to invent persistent constraints, failure-derived learning, or runtime action enforcement. The contribution here is the evidence-bound workflow in the RYO practice-trading context and the immutable link from T0/T1 receipts to the rule that changes the future action space.
